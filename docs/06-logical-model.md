# Модели мантиқии пойгоҳи додаҳо: ASTAT SCRUM

## 1. Ҷадвали ибтидоӣ (ғайринормалӣ)

Барои таҳлили ASTAT SCRUM ҷадвали шартии Excel-и идоракунии лоиҳаҳо ва вазифаҳо истифода мешавад. Маълумот тахайюлӣ буда, танҳо барои нишон додани қадамҳои нормализатсия оварда шудааст.

| Лоиҳа | Роҳбари лоиҳа | Аъзоёни гурӯҳ | Вазифа | Иҷрокунанда | Спринт | Шарҳҳо | Вақти сарфшуда |
|---|---|---|---|---|---|---|---|
| ASTAT SCRUM | Фарҳод Раҳимов | Мадина Назарова, Али Саидов | Тарҳрезии саҳифаи воридшавӣ | Мадина Назарова | Sprint 1 | Тарҳ тасдиқ шуд; Ислоҳи майдонҳо лозим | 2 соат; 1 соат |
| ASTAT SCRUM | Фарҳод Раҳимов | Мадина Назарова, Али Саидов | Сохтани ҷадвали вазифаҳо | Али Саидов | Sprint 1 | Ҷадвал сохта шуд | 3 соат |
| Website Redesign | Саид Каримов | Фарҳод Раҳимов, Мадина Назарова | Навсозии саҳифаи асосӣ | Фарҳод Раҳимов | Sprint 2 | Макет омода аст | 4 соат |

Ин ҷадвал ғайринормалӣ аст: дар сутуни «Аъзоёни гурӯҳ» якчанд қимат, дар «Шарҳҳо» якчанд шарҳ ва дар «Вақти сарфшуда» якчанд сабт нигоҳ дошта мешавад. Илова бар ин, маълумоти лоиҳа, корбар, спринт ва вазифа такрор мешавад.

## 2. Нормализатсия

### 2.1. Шакли якуми нормалӣ (1ШН)

**Мушкилот:**
- «Аъзоёни гурӯҳ» якчанд корбарро дар як ҳуҷайра нигоҳ медорад.
- «Шарҳҳо» ва «Вақти сарфшуда» гурӯҳҳои такроршаванда мебошанд.
- Як ҳуҷайра бояд танҳо як қимати атомӣ дошта бошад.

**Ислоҳ:**
- Барои ҳар аъзои гурӯҳ сабти алоҳидаи узвият ташкил карда мешавад.
- Ҳар шарҳ ба сабти алоҳидаи `comments` мегузарад.
- Ҳар сабти вақт ба сатри алоҳидаи `time_entries` мегузарад.
- Ҳар вазифа дар як сатр нигоҳ дошта мешавад.

Пас аз 1ШН ҳар майдон атомӣ аст, вале маълумоти лоиҳа, корбар ва спринт ҳанӯз дар сатрҳои гуногун такрор шуда метавонад.

### 2.2. Шакли дуюми нормалӣ (2ШН)

**Мушкилот:**
Дар ҷадвали пайвасткунандаи ибтидоии узвият калиди таркибии `(project_id, user_id)` истифода шуда метавонад. Агар номи корбар ё почтаи электронӣ дар ҳамин ҷадвал нигоҳ дошта шавад, онҳо танҳо аз `user_id` вобастаанд, на аз тамоми калиди таркибӣ. Ҳамчунин номи лоиҳа танҳо аз `project_id` вобаста аст.

**Ислоҳ:**
- Маълумоти корбар ба `users` гузаронида мешавад.
- Маълумоти лоиҳа ба `projects` гузаронида мешавад.
- Ҷадвали `project_members` танҳо маълумоти узвиятро нигоҳ медорад: `project_id`, `user_id`, `role`, `joined_at`.
- Калиди асосии суррогатии `id` дар ҳамаи ҷадвалҳо истифода мешавад; барои узвияти такрорӣ маҳдудияти `UNIQUE(project_id, user_id)` гузошта мешавад.

Ҳамин тавр, вобастагии қисмӣ бартараф мешавад.

### 2.3. Шакли сеюми нормалӣ (3ШН)

**Вобастагиҳои транзитивӣ ва ҳалли онҳо:**

| Вобастагӣ | Мушкилот | Ҳалли 3ШН |
|---|---|---|
| `task_id → sprint_id → sprint_name, start_date, end_date, status` | Маълумоти спринтро дар ҳар вазифа такрор кардан лозим меомад | Маълумоти спринт дар `sprints`, вазифа танҳо `sprint_id` нигоҳ медорад |
| `task_id → project_id → project_name, description` | Номи лоиҳа аз вазифа не, аз лоиҳа вобаста аст | Маълумоти лоиҳа дар `projects`, вазифа танҳо `project_id` нигоҳ медорад |
| `comment_id → user_id → username, email` | Номи муаллиф ва почтаи электронӣ дар шарҳ такрор мешаванд | Маълумоти шахс дар `users`, шарҳ танҳо `user_id` нигоҳ медорад |
| `time_entry_id → user_id → username` | Номи корбар дар ҳар сабти вақт такрор мешавад | `time_entries.user_id` ба `users.id` ишора мекунад |

**Натиҷа:** ҳар ҷадвал як мавзӯи мустақилро тавсиф мекунад. Атрибутҳои ғайрикалидӣ аз калиди ҷадвали худ вобастаанд, на аз атрибутҳои ғайрикалидии дигар.

## 4. Алоқаҳо

| Алоқа | Навъ | Калиди берунӣ | Шарҳ |
|---|---|---|---|
| users — projects (соҳиб) | 1:N | projects.owner_id | Як корбар метавонад якчанд лоиҳа дошта бошад |
| users — projects (аъзоён) | M:N | project_members.project_id, project_members.user_id | Ҷадвали пайвасткунандаи `project_members` |
| projects — sprints | 1:N | sprints.project_id | Ҳар спринт ба як лоиҳа тааллуқ дорад |
| projects — tasks | 1:N | tasks.project_id | Ҳар вазифа ба як лоиҳа тааллуқ дорад |
| sprints — tasks | 1:N | tasks.sprint_id | Вазифа метавонад берун аз спринт бошад |
| tasks — comments | 1:N | comments.task_id | Як вазифа метавонад шарҳҳои зиёд дошта бошад |
| tasks — time_entries | 1:N | time_entries.task_id | Як вазифа метавонад сабтҳои зиёди вақт дошта бошад |
| users — comments | 1:N | comments.user_id | Як корбар метавонад шарҳҳои зиёд нависад |
| users — time_entries | 1:N | time_entries.user_id | Як корбар метавонад вақти зиёдеро сабт кунад |

**Алоқаи M:N:** як корбар метавонад узви якчанд лоиҳа бошад ва як лоиҳа метавонад якчанд аъзо дошта бошад. Ин алоқа тавассути `project_members` ба ду алоқаи 1:N ҷудо шудааст.

## 5. Маҳдудиятҳои бутунӣ

### UNIQUE
1. `users.username` — номи воридшавӣ бояд ягона бошад.
2. `users.email` — почтаи электронӣ бояд ягона бошад.
3. `project_members(project_id, user_id)` — як корбар дар як лоиҳа танҳо як маротиба сабт мешавад.

### CHECK
- `tasks.priority BETWEEN 1 AND 4`.
- `time_entries.minutes > 0`.
- `sprints.end_date IS NULL OR sprints.start_date IS NULL OR sprints.end_date >= sprints.start_date`.

### Қоидаҳои ON DELETE

| FK | Қоида | Сабаб |
|---|---|---|
| projects.owner_id → users.id | RESTRICT | Корбаре, ки лоиҳа дорад, бе таъини соҳиби дигар нест карда намешавад |
| project_members.project_id → projects.id | CASCADE | Ҳангоми нест шудани лоиҳа узвиятҳои он низ нест мешаванд |
| project_members.user_id → users.id | CASCADE | Ҳангоми нест шудани корбар сабтҳои узвияти ӯ нест мешаванд |
| sprints.project_id → projects.id | CASCADE | Спринтҳои лоиҳаи нестшуда нигоҳ дошта намешаванд |
| tasks.project_id → projects.id | CASCADE | Вазифаҳо қисми лоиҳа мебошанд |
| tasks.sprint_id → sprints.id | SET NULL | Нест шудани спринт вазифаро аз байн намебарад, танҳо спринтро ҷудо мекунад |
| tasks.created_by → users.id | RESTRICT | Офарандаи вазифа бояд нигоҳ дошта шавад |
| tasks.assigned_to → users.id | SET NULL | Ҳангоми нест шудани иҷрокунанда вазифа бе иҷрокунанда мемонад |
| comments.task_id → tasks.id | CASCADE | Шарҳ бе вазифаи вобаста маъно надорад |
| comments.user_id → users.id | RESTRICT | Муаллифи шарҳ бояд нигоҳ дошта шавад |
| time_entries.task_id → tasks.id | CASCADE | Сабти вақт бе вазифаи вобаста маъно надорад |
| time_entries.user_id → users.id | RESTRICT | Муаллифи сабти вақт бояд нигоҳ дошта шавад |

## 6. Санҷиши мувофиқат бо 3ШН

- Ҳамаи майдонҳо атомӣ мебошанд; рӯйхати аъзоён, шарҳҳо ё сабтҳои вақт дар як ҳуҷайра нигоҳ дошта намешаванд.
- Ҳар ҷадвал калиди асосии ягона дорад.
- Маълумоти корбар, лоиҳа, спринт ва вазифа дар ҷадвалҳои алоҳида нигоҳ дошта мешавад.
- Маълумоти такрории лоиҳа дар ҳар вазифа ва маълумоти корбар дар ҳар шарҳ такрор намешавад.
- Алоқаи M:N тавассути `project_members` амалӣ шудааст.

## 7. Эзоҳ оид ба татбиқ

Ин ҳуҷҷат модели мантиқии пешниҳодшуда барои ASTAT SCRUM мебошад ва ба синфҳои домении кори лаборатории №5 мувофиқ карда шудааст: `User`, `Project`, `ProjectMember`, `Task`, `Sprint`, `Comment`, `TimeEntry`. Он тавсифи модели пойгоҳи додаҳо мебошад; пеш аз истифода ҳамчун SQL-и истеҳсолӣ бояд номҳо ва маҳдудиятҳо бо сохтори воқеии ҷадвалҳои MySQL муқоиса карда шаванд.
