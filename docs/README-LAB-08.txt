# Куда поместить файлы лабораторной №8

Скопируйте `08-technical-specification.md` в папку `docs` вашего репозитория:

```text
scrum/
└── docs/
    └── 08-technical-specification.md
```

Для отображения всех семи диаграмм в GitHub в том же `docs/` должны находиться папки и изображения из лабораторных №4–7:
- `04-behavior/use-case.png`
- `04-behavior/activity-sprint.png`
- `04-behavior/sequence-task-status.png`
- `05-structure/class.png`
- `05-structure/component.png`
- `06-er-diagram.png`
- `07-deployment.png`

Не удаляйте и не заменяйте существующие папки. Если какого-либо файла нет или его имя отличается, исправьте относительный путь в Markdown либо добавьте правильный файл.
